DocuSketch embed test

Lobdell timeline project: pre-loss KzySXm4D, post-construction nBn_UTAd. Three ways to put a walkthrough on a page, each with the code used.

Option 1

Preview strip embed (opens in a popup)

Lightweight animated preview of the first panorama. Clicking opens the full tour in a lightbox. Good for a gallery page with many projects. Loads jQuery and Colorbox from DocuSketch.

Note: the snippet copied from the portal has data-env="production". That value makes the script call production.docusketch.com, which does not resolve, so nothing renders. Use data-env="app" (or omit the attribute) until the snippet is fixed.

Code 
<script type="text/javascript"
  src="https://app.docusketch.com/portal-cc/assets/javascripts/embedcode-utils.js"
  data-env="app"></script>
<a id="3239638" attr-publicID=KzySXm4D class="iframe embed-container" style="display: inline-block;">
  <canvas width="400" height="200"></canvas>
</a>

Option 3

Before and after in one player (Timeline Compare Mode)

One iframe of a project that has timelines. The public player shows the timeline bar across the top (Pre Loss, Mitigation, Post Construction). The split-screen button beside it opens Compare Mode with Side by side, Split, and Sync. No custom layout needed, and it's the plain iframe embed.

Code 
<div style="max-width: 100%; padding-bottom: 56.25%; position: relative; height: 0; overflow: hidden; ">
  <iframe webkitAllowFullScreen mozallowfullscreen allowFullScreen frameborder="0"
    id="iframeTour-KzySXm4D"
    style="position: absolute; top: 0; left: 0; width: 100%; height: 100%"
    src="https://app.docusketch.com/player/KzySXm4D"></iframe>
</div>
